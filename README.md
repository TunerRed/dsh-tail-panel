# dsh-tail-panel — DSH 运行日志尾巴

长任务跑到一半不说话的时候，最难受的是：**不知道它是在思考、在跑工具，还是卡死了。**

这个插件把 DSH 自己的会话日志（`session.v4.jsonl.zstd`）实时尾巴化，塞进侧边栏一页，随时能看。

## 能看到什么

| 行 | 含义 |
| --- | --- |
| `▶ 第 N 轮 开始` / `⏹ 第 N 轮 结束（completed）` | 轮次边界 |
| `· 第 N.M 步` | 每一步（一次模型调用） |
| `💭 思考` / `💬 回复` | 模型的思考与正文（截断到 200 字） |
| `🔧 工具名  参数摘要` | 工具调用，参数里挑最有信息量的那个字段 |
| `✔ / ✖ 工具名  耗时  结果首行` | 工具结果，报错/非零退出标红 |
| `🛠 后台任务` | 后台 job 的注册与结束 |
| `👤 用户` | 你发的话（记忆注入、system-reminder 等噪音已过滤） |
| `⚙ 模型` / `📝 标题` / `☑ 待办` / `⚠ 钩子` | 模型切换、会话重命名、待办进度、钩子拦截 |

头部状态条是关键：

- 有工具在跑 → `⌛ ops_bash 已跑 12s`（蓝点跳动）
- 在模型思考 → `第 10.34 步 · 空闲 8s`
- 超过 15 秒没动静 → 黄点 + `⚠ 空闲 41s`
- 超过 60 秒 → 红点提醒

## 使用

1. 右侧边栏 → `+` 菜单 → **日志尾巴**（会自动对上当前会话）
2. 或者点输入框左边的 🪵 按钮，直接把那一页叫出来

页内按钮：`⏸ 暂停` / `🔄 重载`（从头拉最近日志）/ `🧹 清屏` / `📋 复制`。下拉框可以切到别的会话去围观。

## 原理

- 宿主侧（`index.js` + `lib/tail-core.js`）注册 `GET /dsh-tail-api`，只认本机（Host 头必须是回环地址）。
  `op=list` 列会话，`op=tail&session=&after=` 增量吐格式化好的行。
- 会话文件是**多帧拼接的 zstd**，Node 自带 `zstdDecompressSync` 只解第一帧，所以 `lib/tail-core.js` 里带了一个帧遍历器：读帧头 → 逐 block 跳到帧尾 → 每帧单独解压 → 按行 `JSON.parse`。
- 前端每 1.2 秒拉一次增量（`after` 游标），只 append，不重绘历史。

## 装/卸

```bash
dsh plugin --profile desktop add link:E:\workspace\plugins\dsh-tail-panel   # 装（重启 DSH 生效）
dsh plugin --profile desktop remove dsh-tail-panel                          # 卸
```

## 已知限制

- 会话日志本身是**顺序写**的：某个 turn 还没落盘完时，尾巴只能看到已经 flush 的事件，看不到模型正在生成的字（模型思考中显示为「空闲 Ns」）。
- 只读 `*.zstd`，不读 `.tmp`（正在写的临时文件）。
- 数据根自动探测：`$DSH_HOME/data/sessions`、`$DSH_HOME/sessions`、`~\.dsh\...`。
